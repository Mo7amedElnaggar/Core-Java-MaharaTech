# Lab Exercise

Develop an application that performs the following tasks:

1. Generate or use an array containing **1000 elements**.
2. Find the **minimum** and **maximum** values in the array.
3. Measure and display the execution time required to perform the search.

After that:

1. Rewrite the application using the **Binary Search** algorithm.
2. Measure and display the execution time of the binary search implementation.
3. Compare the execution times of the two approaches.

> **Hint:** Use `System.currentTimeMillis()` or `System.nanoTime()` to measure the execution time.
