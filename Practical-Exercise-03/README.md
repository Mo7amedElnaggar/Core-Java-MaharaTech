# Lab Exercise

## Problem Statement

Given a **sentence** and a **word**, your task is to count the number of occurrences of the given word in the sentence and print the total number of occurrences.

---

## Tasks

### 1. Using Only the `String` Class (2 Ways)

Implement the solution using only methods available in the `String` class.

### 2. Using the `StringTokenizer` Class

Implement the same solution using the `StringTokenizer` class.
